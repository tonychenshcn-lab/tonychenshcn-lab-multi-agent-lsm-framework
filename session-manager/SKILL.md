# Session Manager

## 技术规范与运行机制
本模块是防止大语言模型上下文溢出的底层基础防线。
基于 Mac 原生 `fsevents` 文件监听实现零轮询 I/O 开销。

## 后置拦截操作流 (LSM-Tree 任务迁移规范)
当监控引擎触发 L1 缓存刷新或由于上下文污染发起物理熔断时，新老会话交接**必须严格遵循以下后台任务迁移生命周期**：
1. 【任务交接记录】：在抛弃旧会话前，必须要求旧会话调用 `manage_task` 获取其名下的所有 Task ID，并将其记录至 `_Archive.md` 或交接文件中。
2. 【孤儿进程扑杀】：新建会话后，大模型必须读取旧会话留下的 Task ID，调用工具物理 `kill` 掉这些遗留在后台的僵尸定时器。
3. **【新任务热启动】**：大模型在受令读取并加载 `_SOP.md` (L1 热库) 完毕的同一运转周期内，必须根据参数自主调用 `schedule` 等工具重新挂载业务定时跑批任务。
