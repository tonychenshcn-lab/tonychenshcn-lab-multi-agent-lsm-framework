### 历史事件与排障归档 (2026-10)

#### 事件一：工具调用参数越权拦截 (2026-10-01)
- **问题描述**：在尝试生成 10月2日 国庆特刊时，Agent 错误调用了 `run_command` 的非标准参数 `BypassSandbox: true`，被底层系统拦截并抛出 `additional properties 'BypassSandbox' not allowed` 错误。
- **排障堆栈**：立即降级至标准传参，仅保留 `CommandLine`, `Cwd`, `WaitMsBeforeAsync` 等合法参数，成功执行脚本。
- **沉淀结论**：绝对禁止在工具调用中主观捏造或猜测参数（如提权、绕过安全沙箱等指令），必须严格遵循系统开放的 JSON Schema 接口定义。

#### 事件二：国庆长假休市数据自适应 (2026-10-01)
- **问题描述**：10月1日 Alpha_Market国庆长假休市，常规资金流及指数 API (`Data_Provider_B`, `Sina`) 将返回空缺或过时数据。
- **排障堆栈**：在生成 DOCX 时，Agent 智能识别了休市状态，主动跳过了对国内市场数据的 API 抓取，直接在 DOM 层硬重写注入“Alpha_Market因国庆假期持续休市，暂无新数据产生”，并主动清空了相关资金流入表格的单元格（写入 `-`）。
- **沉淀结论**：在遇到节假日等结构性停机时，必须具备“非强依赖断路器”逻辑，主动停止无效重试，以静默占位符保证排版不崩溃。
