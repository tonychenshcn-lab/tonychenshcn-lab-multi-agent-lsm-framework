# Video_Platform_Y 自动化工作流排错与踩坑归档 (Archive)

本文档记录了在构建 Video_Platform_Y Lofi 视频全自动化工作流过程中遇到的技术坑点、问题排查记录及对应的解决方案。

## 1. 架构与 API 限制
- **原定计划的阻碍**：最初计划由 Agent 直接调用 API 自动完成所有文本和音视频生成。
- **调整原因**：由于 Google Flow 和 Claude API 均需要绑卡计费或遇到验证障碍。
- **最终方案**：改为“人机协同 (Human-in-the-loop)”方案，Agent 负责写脚本、建文件、全自动 FFmpeg 音视频剪辑合成，User 负责通过界面生图、生视频和发布。
- **工作区同步**：利用 Google Drive 桌面版客户端（`/Users/<USER>/Library/CloudStorage/GoogleDrive-...`）作为共享工作区，实现脚本读写自动云端同步。注意大视频生成后，云端同步需要时间。

## 2. 视频拼接与画面处理问题
- **AI 视频跳帧问题**：AI 生成的视频结尾处常发生画面漂移，导致多段拼接时首尾不连贯。
  - **解决方案**：引入 `auto_trim.py`。提取下一段视频首帧，在上一段视频末尾 4 秒内逐帧回溯比对结构相似度 (SSIM)。找到 SSIM ≥ 0.95 的回归帧，利用 FFmpeg 自动切除后续多余部分。
- **严格把控阈值**：即使匹配度达到 0.949，也会被程序拦截拦截。原则上**坚决不降低 0.95 阈值**，只允许报出具体误差由人工放行或重新生成。
- **分辨率必须为偶数报错**：首尾图片原本比例（1365x768）无法被 H.264 (YUV420p) 编码器处理。开发了 `crop_images.sh`，强制裁切原图到完美的偶数像素 16:9 或 9:16 比例。
- **开头黑屏问题**：多视频合并时由于时间戳错位导致开头黑屏。废弃了多段物理拼接，改用循环拷贝 (`-shortest`)，并强制加入 `-fflags +genpts` 重建梳理时间戳。

## 3. 音频拼接与处理问题
- **视频自带杂音**：直接拼接导致 AI 视频环境音暴露。
  - **解决方案**：利用 `-map 0:v -map 1:a` 强制剥离视频原声。
- **音频截断在 49 分钟的问题**：
  - **原因 1 (音乐时长盲盒)**：21 首歌时长不足 1 小时。解决方案改为指定 26-30 首歌。脚本中利用截断技术强制 `3600 秒` 一刀切，并配合最后 10 秒 `afade` 滤镜自然淡出。
  - **原因 2 (符号导致崩溃)**：音乐库中存在带英文单引号的歌名（如 `Dreamer's Heartbeat`），导致 FFmpeg 拼接直接崩溃。
  - **解决方案**：在 bash 脚本中加入强效转义清洗逻辑，实现单引号免疫。

## 4. 封面排版与短视频字幕 (Render 问题)
- **字体与排版不美观**：原有的 Arial 字体突兀。
  - **解决方案**：封面更新为 Georgia Bold 衬线体，短视频使用苹方/黑体 (STHeiti) 保证中文渲染。
- **Emoji 导致渲染方块/乱码**：FFmpeg/PIL 使用英文字库时无法识别 `📚` 等 Emoji。
  - **解决方案**：增加智能正则过滤层，生成封面时剔除文本中的所有 Emoji。
- **文字遮挡与识别**：
  - 封面通过方差计算找出画面中“最干净”的留白位置进行文字叠加。短视频钩子过长时则以逗号自动分行居中显示。

## 5. 多项目会话污染 (Agent 致命错误)
- **事件**：在 Video_Platform_Y 会话中，由于服务器重启，Agent 自动唤醒并错误挂载了隔壁 HR 项目的“简历 JD 匹配”定时任务。
- **根因**：全局 `MEMORY.md` 触发自愈协议时，未做当前上下文校验。
- **修复措施**：强行 Kill 错误任务，彻底修改 `MEMORY.md` 规则，强制实施**上下文和会话隔离校验**，禁止跨项目恢复后台任务。
